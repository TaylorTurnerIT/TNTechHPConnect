# TN Tech HPC overview (public mirror of https://www.rcd.tntech.edu/hpc, 2026-09-16)

Research Computing and Data (RCD) staff manage the campus HPC facility, and facilitate
access to federally-funded HPC and private cloud resources, including NSF ACCESS and
NAIRR Pilot, and DOE ASCR.

## On campus

HPC facility: Clement Hall 226. Clusters: **Impulse** (2017) and **Warp 1** (2022,
NSF Award 2127188). Managed by Information Technology Services (ITS). Available to all
students, faculty, staff for computationally intensive research/classes after a brief
consultation.

- Impulse: 42 CPU nodes x 28 cores (Intel Xeon E5-2680v4 2.4 GHz), 64–896 GB RAM;
  2 GPU nodes x 28 cores + 384 GB RAM + 2x NVIDIA K80 (4 GPU devices); 56 Gb IB.
- Warp 1: 10 GPU nodes x 128 cores (AMD Epyc 7713 2.0 GHz), 512 GB RAM,
  2x 40 GB NVIDIA A100; 100 Gb IB.
- Shared storage: ~300 TB NFS all-flash (175 TB on older docs).
- Software: AI/ML, bioinformatics, CFD, FEA, molecular dynamics + secure containers
  (reproducible research / mobility).
- Help: software install/licensing, queueing system, workflows, training.

Contacts: Mike Renfro (931-372-3601, Clement Hall 220), MS Teams team, appointments.
Links: user documentation (login may be required), HPC account request (login required).

## Off campus (federally funded, zero-cost via RCD)

- NSF ACCESS (access-ci.org): 30+ resources; RCD staff help select; project live in days.
- NAIRR Pilot (nairrpilot.org): NSF + 10 federal agencies + 25 non-gov (Anthropic, Google,
  Meta, Microsoft, OpenAI); commercial AI models/inference/SaaS at no cost.
- DOE ASCR: INCITE (multi-year, Oak Ridge/Argonne majority machine), ALCC (1-yr),
  ERCAP (1-yr, NERSC), Center Reserves (1-yr discretionary).
